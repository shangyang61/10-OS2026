# 实验报告截图

将本人实际截取的 PNG 保存到本目录。当前只有截图位置说明，没有预造截图。

| 文件名 | 内容 |
|---|---|
| S01_environment.png | 补图机器、代码版本、编译器与 QEMU |
| S02_bestfit_grade.png | 保护检查、10/10 边界和 20/20 原始评分 |
| S03_buddy_tests.png | Buddy 六组及独立 SLUB 八组 |
| S04_slub_bestfit.png | Best-Fit 下独立 SLUB 八组 |
| S05_page_init_gdb.png | 页初始化完成后的变量与根表 |
| S06_mmu_walk.png | Sv39 查询和翻译结果 |
| S07_tlb_miss_fill.png | 同次缺失和填充 |
| S08_tlb_hit.png | 同一页后续命中 |

分成子图时在文件名后加 _a、_b，并同步修改报告图片语句。图注区分本机新运行与原始日志复核，旧内核地址不能冒充新内核现场。
